# PROJETO MARKETPLACE (MERCADO LIVRE) - JORNADA DEV EFICIENTE

Projeto desenvolvido durante o treinando da Jornada DEV EFICIENTE. 
- Tecnologias utilizadas:
  * Java 21
  * Spring Boot 4.0.3
  * Spring Security
  * Banco de dados relacional (PostgreSQL)
  * Docker (para executar o banco)

- Neste projeto pratiquei:
  * Segurança com Spring Security;
  * JWT;
  * Salvar senhas utilizando algoritmo de hash;
  * Testes automatizados (unitários e integração);
  * Validações personalizadas com Bean Validation, criando anotações com regras específicas de validação;

 - Conceitos que foram passados no treinamento:
   * Controller 100% coesas;
   * Cognitive-Driven Development (CDD);
